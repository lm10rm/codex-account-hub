# Codex Account Hub

一个面向 Windows 的本地 Codex 多账号额度看板与安全切换工具。

无需来回退出登录，即可查看多个账号的剩余额度、重置时间和重置券；需要切换时，应用会先备份当前认证，再切换账号并重新启动 Codex。

## 功能

- 同时查看多个 Codex 账号的主要额度、周额度和重置时间。
- 当前账号自动置顶，并提供低额度颜色提示。
- 使用官方 Codex App Server 读取额度，不依赖网页抓取。
- 通过官方 Codex 登录页面添加或重新授权账号。
- 一键切换账号并重新启动 Codex，也可选择仅切换。
- 支持账号重命名、单独刷新和删除。
- 支持浅色与深色主题。
- 使用 Windows DPAPI 加密保存认证信息。

## 安装

前往 [GitHub Releases](https://github.com/lm10rm/codex-account-hub/releases/latest) 下载最新的 Windows x64 安装包：

```text
Codex Account Hub_0.2.1_x64-setup.exe
```

安装包使用当前用户模式，不需要管理员权限。安装后可从桌面快捷方式或开始菜单启动，不会打开额外的终端窗口。

> 当前发布包尚未进行商业代码签名，Windows SmartScreen 可能显示未知发布者提示。请只从本仓库的 Releases 页面下载。

## 使用

1. 先在 Codex 桌面端或 CLI 中登录一个账号。
2. 打开 Codex Account Hub，点击“导入当前账号”。
3. 点击“添加账号”，在打开的官方页面中完成另一个账号的登录。
4. 应用会依次读取所有已保存账号的额度。
5. 点击“切换并重启”，确认后应用会保存当前账号、切换认证并重新打开 Codex。

切换会关闭正在运行的 Codex 窗口和任务，请先保存重要工作。

## 数据与安全

- OAuth 凭据仅保存在本机，并使用当前 Windows 用户的 DPAPI 加密。
- 应用不会要求或保存 OpenAI 账号密码。
- 额度读取由本机官方 Codex 进程完成。
- 不提供复制、导出或上传 token 的功能。
- 不会自动轮换账号，也不会绕过账号额度或公平使用限制。

完整说明见 [SECURITY.md](SECURITY.md)。

## 当前限制

- 仅支持 Windows x64。
- 额度缓存目前只在本次应用运行期间保留。
- 尚未提供托盘、开机启动和自动更新。
- 安装包尚未进行代码签名。
- Codex 桌面端或 App Server 协议升级后，可能需要同步适配。
